# README

This is README for manuscript ***The influence of demographic history and genetic architecture on complex traits via runs of homozygosity*** by Mingzuyu Pan and Zachary A Szpiech (https://www.biorxiv.org/content/10.64898/2025.12.17.694908v2). The purpose of this README is to describe the complete simulation and analysis workflow involved in the manuscript. If you have questions, please contact Mingzuyu (mzp5919@psu.edu).

## Directory Organization

The files and data in this repository are organized as follows:

- **`1_Simulation_and_analysis`**: Contains all scripts for the core workflow, corresponding to the sections: *Preparation and notes*, *Simulation and Calling ROH*, *Generate phenotype scores*, *Analysis*, and the execution commands (*To run all the scripts above*).
- **`2_Data`**: Stores the raw data generated by the whole pipeline.
- **`3_Plot`**: Contains codes for processing data, visualization (plotting), and statistical analysis.
- **`4_Supplemental_material`**: Archives the necessary statistical test results, analysis results, and other supplemental materials generated during the plotting step.

## Simulation and Calling ROH

`gravel_chr1_100Mbp_treeseq_del_only_h00.slim` : SLiM simulation where all deleterious mutations are fully recessive.

`gravel_chr1_100Mbp_treeseq_del_only_h05.slim` : SLiM simulation where all deleterious mutations are fully additive.

`gravel_chr1_100Mbp_treeseq_del_only_h10.slim` : SLiM simulation where all deleterious mutations are fully dominant.

`gravel_chr1_100Mbp_treeseq_del_only_h15.slim` : SLiM simulation where the deleterious mutations have mixed dominance coefficient.

`genetic_map_chr1_b37_100Mbp.txt` : to define realistic genomic regions for SLiM simulation.

`ccdsGene.chr1.100Mbps.exons.uniq.noverlap.txt` : to set up realistic recombination rate map in SLiM

`generate_neutral_muts_and_vcf_by_pop2.py` : to overlay neutral mutations on the treesequence generated by SLiM simulation and randomly sample 500 individuals from each population.

`plink.chr1.GRCh37.map` : to convert physical positions (bp) to genetic distances (cM) when calling ROH

`dummy.centromeres.txt` : to tell GARLIC that there are no centromeres in the data that’s being analyzed

`calculate_ROH_fractions.pl` : to calculate the sum of the lengths of each type of ROH in each individual

`run_sim_modified.py` : use a single script to: run SLiM simulation, overlay neutral mutations, sample, call ROHs, calculate the total length of each ROH category per individual, and clean up intermediate files.

## Generate phenotype scores

### *Preparation*

`get_simID(simplified).py` : to get the simulation ID of each replicate. The ID is used in following calculation and analysis.

### *Deleterious mutations*

`generate_phenotype_scores.py` : to calculate the phenotype scores for each variant with given selection coefficient, tau, and rho.

`compute_phenotype_in_roh_sims.pl` : to calculate the total phenotype score contributed by deleterious mutations from each of the three types of ROH regions and non-ROH regions within each individual.

`run_pheno_simple.py` : This script modifies the value of tau. It then loops through the two scripts above to compute the phenotype scores for different tau values.

### *Neutral mutations*

`del_mutation_calculate_per_replicate.py` : to get total number of deleterious mutations of each replicate.

`to_get_distribution.py` : to fit the number of deleterious mutations across 500 replicates to a normal distribution.

`to_get_neutral_mutations_in_exon.py`: This script filters VCF files to extract variants located in exon regions and then randomly samples a specific number of these sites based on a count derived from the normal distribution.

`sample_mutations_from_all_in_exon.py`: This script identifies and extracts variant records from the original VCF file based on the list of sampling positions generated in the previous step, generating the final sampled VCF file of each population.

`get_feature_file_for_neutral.py`: This script generated the score per variant, which is similar to deleterious scenario.

`neutral_pheno_modified.py` : Similar to deleterious scenario, this script also calculates the total phenotype score contributed by neutral mutations from each of the three types of ROH regions and non-ROH regions within each individual.

`run_pheno_neutral_all_commands.sh`: This script runs through the scripts above and modifies the value of tau to compute the phenotype scores contributed by neutral mutations.

`to_normalize_phenotype_score.R` : This scripts normalizes the phenotype scores across the different populations.

## Analysis

We ran the above pipelines for 500 replicates. Based on the raw data we got, we ran following data analysis:

`process_data_frac_deleterious.py`, `process_data_frac_neutral.py` : Calculate the per-cM phenotype score contribution of each ROH region and non-ROH region within each replicate (consider only individuals within that replicate who have the region with a non-zero phenotype score contribution). The output data of this step is: `hXX_summary_frac_deleterious_normalized.xlsx` and `hXX_summary_frac_neutral_normalized.xlsx`.

`process_data_proportion_deleterious.py`, `process_data_proportion_neutral.py` ,`proportion_mean_ste_cal.py`: Calculate the proportion of phenotype score explained by each ROH region and non-ROH region within each replicate (consider all the individuals within the replicate). The output data of this step is: `hXX_summary_proportion_delterious_normalized.xlsx` and `hXX_summary_proportion_neutral_normalized.xlsx`.

`calculate_0_proportion_deleterious.py`, `calculate_0_proportion_neutral.py` : Calculate the proportion of individuals: 1. without a specific ROH region; 2. have the ROH region but no phenotype score contribution from the region; 3. have the ROH region with non-zero phenotype score contribution. The output data of this step is: `calculate_0_proportion_neutral.csv` and `calculate_0_proportion_deleterious.csv`.

## To run all the scripts above

Remember to change the head settings in each bash file for your own cluster. Ideally you only need to submit `job_submit.sh` to run the whole pipeline.

`command_file_general_X.sh` and `run_pheno_neutral_all_commands.sh` are bash files to run the above steps separately. You can submit them manually to test parameters or for any modification, but please remember to follow the order of all the scripts. `job_submit.sh` just unites all the bash files to make it easier to submit.

## Plot

`plot_fraction_reorganized.R` : To plot the per-cM phenotype score contribution of different ROH and non-ROH regions (Figure 2, 4, S1, S2). Remember to run this script first, because the output of script is the input of other plotting scripts.

`plot_0_proportion_deleterious.R`, `plot_0_proportion_neutral.R`: To plot the proportion of individuals with different status of ROH regions (Figure 1, 3).

`absolute_change_deleterious_with_se.R`, `absolute_change_neutral_with_se.R` : To plot the change of differences in per-cM phenotype score contribution between ROH and non-ROH regions with tau increasing (Figure 5, 6).

`proportion_plot_with_se_deleterious.R`, `propotion_plot_with_se_neutral.R` : To plot the proportion of phenotype scores explained by different ROH and non-ROH regions (Figure 7, 8), but remember to run `proportion_mean_ste_cal.py` first to calculate the standard error for plotting.

## Robustness Analyses

The `5_Robustness_analyses` directory contains additional analyses addressing robustness of the main results under alternative model specifications, ROH calling methods, and comparisons with empirical data.

Each subdirectory follows a consistent internal structure: analysis and data processing scripts, raw and summary data, and plotting scripts and output figures.

| Directory | Description |
|-----------|-------------|
| `sparse.model` | Sparse causal variant analysis, where only a subset of deleterious mutations are designated as causal alleles (subset proportions: 1.0 and 0.3) |
| `number.of.causal` | Distribution of the number of causal alleles across ROH and non-ROH regions |
| `allele.frequency.spectrum` | Allele frequency spectra of causal variants, partitioned by ROH status |
| `germline` | Comparison of ROH calling between GARLIC and GERMLINE under the fully recessive model across all populations and τ values |
| `only.Mb` | Comparison of ROH classification by physical length (Mb) versus genetic length (cM) under the fully recessive model |
| `1000genomes` | Comparison of simulated ROH patterns with empirical data from the 1000 Genomes Project. Raw 1000 Genomes data are publicly available and not included in this repository; see the manuscript for specific versions used |
| `genetic.variance` | Analysis of genotypic variance decomposition across ROH and non-ROH regions |
